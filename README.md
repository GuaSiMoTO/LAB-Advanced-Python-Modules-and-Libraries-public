## Iteration 1
### Iteration 1.1 / **Generate_random**

Write a function that generates a random decimal number and calculates its absolute value. It then stores the result in a variable called abs_value and displays the value on the screen.

### Iteration 1.2 / **Get_the_floor_and_ceil**

Extends the function so that it calculates the ceiling (value rounded up) and the floor (value rounded down) of the absolute value stored in abs_value . Stores the result in variables and displays the ceiling and floor on the screen.

## Iteration 2
### Iteration 2.1 / **Display_students**

At the academy we have a text file with student information, we need to display each student on the screen in the following format:

Name - emal - course - average grade
Yeray - yeray@example.com – Reboot 11 – 50.5

You can import data from data.txt

### Iteration 2.2 / **Group_the_students** 

To make it more readable, it shows the list of students grouped by course and with the average grade rounded, with this structure:

Course
Name - emal - average grade

Reboot11:
Yeray  - yeray@example.com  – 51
Reboot12:
….

## Iteration 3 / **Add_students**

We have realized that we have forgotten to add 2 students. Implement a function to be able to add the 2 new students and modify the data.txt file

Tony Stark – iamironman@example.com – Reboot 1 – 10
Bruce Wayne – iambatman@example.com – Reboot 1 - 9

## Iteration 4 / **Modify_students**
The student "Mia Lee" has changed her email address and would like to update her information in the academy. Implements the function to modify the data of a user and save the changes in the file data.txt
